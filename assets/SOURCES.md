# Asche zu Asche source game

Downloaded 2026-09-13 from Rammstein World's downloads page:
https://www.rammsteinworld.com/en/multimedia/downloads

- Archive: https://www.rammsteinworld.com/download/aschezuasche.zip
- Local original: `assets/aschezuasche.zip`
- SHA-256: `a71bf41183257fd175340e1113a5e09375ee63083364dc335923137fb64b09d6`
- Extracted, unmodified files: `assets/original/`

The archive contains a 16-bit NE Windows executable, Visual Basic 3 runtime,
RAMM16.DLL and WAV audio. Its German readme specifies Windows 95, a 486 CPU,
8 MB RAM and 256 colours. Archive file dates are November 1997.

The original high-score competition used an encrypted `C:\hiscore.txt` file
submitted by email or fax. Those historical instructions are preserved in the
original readme; they are not a current competition or submission service.
